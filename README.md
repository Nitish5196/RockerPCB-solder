# RocketPCB-solder
A rocket shaped PCB which vibrates and lights up (flashing to imitate a lauching rocket) when the button is pressed , it can be used as a cool looking keychain<br>
BOM(Bill Of Materials):<ul>
<li>Battery Holders x2</li>
<li>555 timer x1</li>
<li>Transistors x8</li>
<li>Resistors x10</li>
<li>photoresistor x 1</li>
<li> potentiometer x1</li>
<li>LED x6</li>
<li>push button x1</li>
<li>motor x1</li>
<li>Capacitor x2</li>
</ul><br>
